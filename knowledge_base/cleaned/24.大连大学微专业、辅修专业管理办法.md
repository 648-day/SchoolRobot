# 大连大学微专业、辅修专业及辅修学士学位管理办法

（1998 年制定，2023 年修订）

为适应经济社会发展对高校人才培养的新要求，充分发挥综合性大学优势，促进学科交叉融合，深化产业学院建设等人才培养模式改革，培养复合型人才，提升学生社会竞争力，鼓励学有余力的学生在学习主修专业课程的同时，根据兴趣修读微专业、辅修专业课程。在原有辅修专业、辅修学位管理办法的基础上，修订本办法。

# 一、总则

1.微专业是指学有余力的本科生在攻读主修专业的同时，修读某一领域所需要的核心课程。对完成微专业课程学习并达到要求者，由学校发给微专业证书。微专业不具有学士学位授予资格。鼓励跨学院、跨学科、跨专业组建微专业教学团队，鼓励学院和校内外科研机构、行业企业合作申报微专业。  
2.辅修专业是指学有余力的本科生在攻读主修专业的同时，修读另一个专业的主要课程（如果申请辅修专业学士学位，则要求必须跨专业类修读辅修专业）而获得相应证书的学习方式。具备学士学位授予权的本科专业可开办辅修专业。  
3.开设微专业、辅修专业的学院要根据专业特点和要求，制订微专业、辅修专业人才培养方案，经同专业 3 名以上校外专家评审通过，学院学术委员会或教学指导委员会审议通过，经教务处审定、备案后执行。  
4.微专业、辅修专业教育是学校本科教学工作的重要组成部分，需遵循学校本科教学工作的有关管理规定执行。

# 二、课程设置与教学组织

1.微专业基于现有专业或围绕某个特定行业、领域、研究方向或者核心素养，培养核心素质和技能，构建课程体系，使学习者通过灵活、系统的培养，能够具备一定的专业素养和行业从业能力。每专业开设 $6 { \sim } 8$ 门课程，每门课程${ 2 } \sim 3$ 学分，共设置 $1 2 { \sim } 1 6$ 学分课程。辅修专业基于现有专业设置 $3 0 { \sim } 3 5$ 学分课程，其课程设置需涵盖专业核心课程；申请辅修学士学位要求 $4 0 \sim 4 5$ 学分，还需设置毕业论文（设计）环节。辅修专业课程的教学要求与主修专业相同。  
2.微专业和辅修专业的具体教学方式由专业决定。可选插入主修专业课堂；线上线下混合式学习；单独编班，利用双休日、晚间、假期集中授课。原则上学生数不少于 15 人的，建议单独编班组织教学。  
3.微专业、辅修专业的教学管理由开办学院和教务处共同负责。开办学院主要负责遴选专业负责人、制订人才培养方案、聘任任课教师，课程安排、课程考试、成绩统计录入、招生和档案管理、毕业审核及学位审核等。教务处负责接受开办申请、开办资格审核、人才培养方案审定、选课、证书授予资格审定等。  
4.申请修读微专业、辅修专业的学生，主修专业的已修课程平均学分绩点要求在 2.5 及以上。  
5.满足绩点要求的学生在校期间根据兴趣可申请一个辅修专业或一个微专业，一般可在每年秋季学期报名。严格课程考核，不及格者不予二考，须重修获得学分。

# 三、毕业要求和证书发放

1.修读微专业的学生，在主修专业毕业前按要求获得微专业培养方案规定的全部学分，学校将授予其大连大学微专业证书。

2.修读辅修专业的学生，符合下列条件可授予相应证书：

（1）同时满足辅修学士学位与主修学士学位归属不同的本科专业类、完成并取得辅修专业培养方案规定的学分、获得主修学士学位授予资格三个条件后，可以授予辅修学士学位。在主修学士学位证书中予以注明，不单独发放学位证书。  
（2）在辅修修读年限内完成并取得辅修专业培养方案规定的学分，发放大连大学辅修专业证书（授予辅修学士学位者除外）。  
3.对于在获得主修专业学位证书时未按照要求修完辅修专业全部学分的，由学生本人向辅修专业提出延长辅修专业学习时长的申请，并自行向主修专业申请延期，但不能超过学校规定的最长学习年限。学生主修专业已毕业或结业，其辅修学习同时终止，不可再申请辅修学位。未能获得主修专业毕业证书者，不单独颁发辅修专业证书。  
4.未完成微专业、辅修专业学习的学生，所修课程学分可以申请认定综合教育选修课学分。

# 四、收费、经费管理

1.按学分收费，按照当年标准执行。如学期中途停止课程学习，已交费用不再退还。  
2.学生每学期须在学校规定的时间内缴纳学费及重修费。逾期不交费者，将取消课程修读资格。

# 五、附则

1.教务处对新开设的微专业、辅修专业在教学改革立项上优先支持。  
2.本办法自发布之日起实施，由教务处负责解释。
