# 大连大学本科学生课程认定及学分转换管理办法

（2010 年制定，2023 年修订）

为适应教育国际化、信息化等发展需要，满足学生个性化学习需求，结合学校实际，特制定本办法。

# 一、适用范围

学校参加境内外校际交流学习的学生、自主学习校内外课程的学生、以及因调整培养方案或学习进程的学生，如转专业、休学、参军等情况。

# 二、基本原则

1.在学校认可的其他高校、科研机构及合作办学单位相关专业修读的且符合学校本科专业培养方案要求，取得成绩及学分的课程方可申请转换。  
2.参加交换学习一学期及以上并通过所在学校对应专业全部课程考试的学生，可以按照分阶段审核的原则进行毕业和学位审核（学生所在我校专业的核心课程和实践环节必须认定或补修）；参加交换学习不足一学期或虽满一学期但未通过所在学校对应专业全部课程的学生，对所修读课程学分进行认定，且获得的总学分不得少于我校培养方案规定学分。  
3.核心课程认定须课程内容相同或相近，非核心课程认定须课程内容有相关性。学位课程原则上不可进行认定，特殊情况须用课程内容相同或相近的核心课程进行认定。思想政治类课程不可用其他类课程认定。辅修专业、微专业课程不可用慕课类课程认定。  
4.理论课程不可以认定实践环节。原则上选修课不可以认定必修课。  
5.参加在线开放课程学习须取得实名认证的有效证书。  
6.所有课程均不可重复认定学分，同一门课程（课程名称相同或相近）重

复修读，只能认定一次。

7.用两门以上课程认定一门课程的，成绩按课程内容相同或相近课程成绩认定。交换学习的成绩和我校成绩的对应关系见下表。

# 三、认定范围

# （一）学校选派交流学生的课程、成绩及学分认定

1.凡学校在读本科生，经学校批准，赴与我校已签署交流合作协议的大学学习所获得的各类课程学分均须认定。  
2.在交换学校修读并取得等级制成绩的课程由学生所在学院认定为我校相应课程成绩。  
3.申请课程认定必须持有交换学校出具的正式成绩单，其中应包含课程名称、类别、学分和成绩等信息。学生应在返校后一个月内填写《大连大学本科学生学分认定表》并提交至所在学院。

# （二）转专业学生修读课程、学习成绩及学分认定

1.学生转入新专业，在原专业修读的所有课程的学分、成绩均记入学生本人的成绩单。  
2.学生在原专业修读课程成绩和学分认定，由转入学院会同开课学院（部）研究决定。原则上同一名称的课程内容相同或相近，可确认有效，以实

际成绩记入；不同名称的课程内容相同或相近，可冲抵转入专业相近的课程，以实际成绩记入。

3.学生在原专业修读过的课程均可认定为综合教育选修课，以实际成绩和学分记入。

# （三）参加辅修学位（专业）或微专业学习的学生修读课程、学习成绩及学分认定

因各种原因中途终止辅修学位（专业）或微专业学习的学生，如所学课程不在主修专业培养方案之内，只可认定为综合教育选修课。冲抵综合教育选修课学分数不超过培养方案中规定的最低要求。

如辅修学位（专业）或微专业与主修专业涵盖同一门课程，且在辅修学位（专业）或微专业培养方案中对该门课程的要求和学时低于主修专业，在学生主修专业已修过该门课程的情况下，可由学生本人提出申请，可认定为辅修学位（专业）或微专业该门课程成绩。

# （四）其他各类学习成绩、学分的认定

各类学习已获得学习成绩或证书的学分认定由学生所在的学院根据学生实际取得的成绩、学分进行认定，并转换为原培养方案中对应的相关课程。

1.通过慕课类学习并获得有效证书可认定相关课程学分。原则上 16 学时及以上的课程认定 1 学分，32 学时及以上的课程认定 2 学分，无学时说明的课程认定 1 学分。每生累计认定不超过 4 学分，成绩合格及以上均按照 60 分进行认定。  
2.学生在校期间通过大学英语四、六级考试，成绩可认定一次大学英语重修成绩；学生参加雅思考试成绩达 6.5 及以上、参加托福考试成绩达 85 及以

上，可申请免试之后的大学英语课程，课程成绩认定为 90 分。该条目涉及的认定需学生到外国语学院办理。

3.获得专业或职业资格证书可认定相应 1门不超过2学分专业课程，认定60 分。  
4.学生作为项目主要参与人（前 3 名），完成省级及以上大学生创新创业计划训练项目，且创新创业累计分数超过 8 分，可直接申请认定一门综合教育选修课，最高记 2 学分。  
5.学生作为参与人（前 5 名）参加学科竞赛获国家级三等奖及以上者，或学生作为负责人参加学科竞赛获省级特等奖、一等奖（学科竞赛项目以创新创业学院每年公布为准），且创新创业累计分数超过 10 分，且未申请过相应课程免试者，可按所在学院已在学校备案的标准，向学院申请认定相应的专业选修课程，最高记 2 学分。

# 四、认定程序

学生填写《大连大学本科学生学分认定表》并附成绩单等相关佐证材料（如参加境内外交换的学生需提交交换学校的专业培养方案）提交至所在学院，学院对学生专业、课程、成绩、学分进行论证、折算、审核并签署意见、盖章后，一式 3 份报送教务处审批，教务处存档 1 份，学生所在学院 2 份（1 份学院存档，1 份装入学生档案），依此进行毕业及学位审核。

本办法自发布之日起开始执行，未尽事宜由教务处负责解释。
